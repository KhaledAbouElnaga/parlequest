# Blue/red identity and daily practice

- A navy blue and red visual identity, with the existing top navigation preserved.
- A dated daily challenge: one grammar correction, one branching conversation, one cultural decision. Activity selection is deterministic for the local date. Levels are captured when the daily plan is first opened (A1 when no level has been selected) and remain fixed for that day.
- Daily completion is saved on the device. Finishing each conversation reaches its terminal scene, including repair branches. Grammar completion requires a correct answer. These activities do not award extra XP.
- A grammar error notebook on Home and My Progress: first-attempt grammar mistakes enter immediately; practice here creates a review record. A correct review is scheduled after 1, 3, 7, then 14 days. A wrong review resets the interval to 10 minutes. This is a simple fixed scheduling rule, not a validated personalized learning model. No push notifications or account synchronization are included.
- Nine additional contextual decisions replace generic follow-up prompts for the university, café and train-station families at A2–B2. The 1,000 contextual locations remain template based. These additions have not been externally reviewed by a FLE teacher.

Validation: build, 23 automated checks (including scheduling, corpus counts and termination of 4,000 level-specific scenario graphs), and browser checks for incorrect/correct answers, all three daily completions, saved completion after reload and notebook entry from ErreurLab.
