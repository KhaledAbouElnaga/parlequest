# ParleQuest v3 — Apprendre le français autrement

منصة فرنسية/عربية مجانية تعمل من المتصفح، دون حساب أو مفاتيح API. الاستضافة الفعلية Cloudflare Pages: https://parlequest.pages.dev/ . محتوى وقواعد مكتوبة، وليست محادثة AI مفتوحة.

## التشغيل والبناء
Node.js 20.19+ أو 22.12+:

```sh
npm install
npm run dev
npm test
npm run build
npm run preview
```

البناء يولّد بنك الأسئلة ثم يفحص TypeScript ويبني الأصول وملف offline. ارفع محتويات `dist` إلى مشروع Cloudflare Pages الموجود `parlequest` كنشر Production. روابط الأصول نسبية. لا يحتاج التشغيل النهائي أي خادم خلفي أو مفتاح API. `.openai/hosting.json` يخص محاولة Sites قديمة، وليس استضافة Cloudflare الفعلية.

## الميزات الفعلية
- اسم أول/مستعار عند الزيارة الأولى فقط. يُحفظ محليًا ويمكن تغييره من لوحة التقدم؛ لا يُرسل لخادم.
- اختيار مستقل للمستوى A1 / A2 / B1 / B2 في الألعاب الثلاث، مع إمكانية التغيير.
- ErreurLab: عدد 1000 سؤال فريد، 250 لكل مستوى؛ تحديد الخطأ وكتابة التصحيح وشرح فرنسي/عربي.
- بنك التمارين مبني صراحةً على 40 نموذجًا نحويًا ×25 تنويعًا معجميًا، وليس 1000 قاعدة مستقلة أو أسئلة امتحان معتمدة.
- Parle Vrai وCultureQuest: مكتبة 1000 سياق مكاني = 25 نوع مكان ×40 مدينة فرنسية. كل سياق متاح بالمستويات الأربعة ويتكون من 6–9 خطوات أساسية، ومسارات إضافية لإصلاح الرد غير المناسب.
- تشمل الأماكن: الإقامة، المستشفى، المقهى، المدرسة، مقابلة صعبة مع المدير، المطعم، الجامعة، النقل، العقارات، البنك، البريد، المكتبة، المتحف، الصيدلية، المخبز، خدمة العملاء، البلدية، الشرطة، التوظيف، الرياضة، الفندق، الإصلاح، التطوع والمسرح.
- المدن حقيقية؛ المؤسسات والقاعات والمواعيد والأرقام في المحاكاة تخيلية. ليس هذا دليلًا إلى ألف مؤسسة موثقة. تشترك المدن في قوالب حوار مع اختلاف معطيات أسئلة الفهم.
- جولات غير محدودة، مع أولوية التمارين غير المحاولة. بعد استنفاد البنك يمكن المراجعة والتكرار، ولا ندّعي محتوى فريدًا لا نهائيًا.
- نقاط أول محاولة: 20 للصحيح و5 للخطأ. تتحدد النتيجة لكل سؤال أو عقدة/مستوى/وضع مرة واحدة؛ إعادة اللعب لا تضاعفها.
- اختبار قواعد داخلي 20 سؤالًا (5 لكل مستوى) يقترح مسارًا تقريبيًا. لا يقيس كل مهارات اللغة وليس اختبار CECRL معتمدًا.
- قسم روابط TV5MONDE لتحديد المستوى السمعي وتدريبات TCF، وروابط نماذج DELF الرسمية من FEI. لا نسخ أو إعادة توزيع للامتحانات، ولا ادعاء اعتماد تدريباتنا.
- حُذف الصوت بالكامل ومحرر المحتوى من الواجهة حسب الطلب.

## التثبيت وPWA
يوجد manifest وأيقونات 192 و512 وService Worker لتخزين الأصول بعد تحميل أول مرة عبر HTTPS. تُحذف فقط مخابئ التطبيق القديمة ذات بادئة pq-. يتفعّل تحديث الذاكرة المؤقتة بعد اكتمال التحميل، دون مسح تقدم المستخدم.

زر التثبيت يلتقط beforeinstallprompt عند توفره، وينتظر تأكيد appinstalled أو وضع standalone قبل عرض «مثبت». عند غياب دعم التثبيت يعرض تعليمات Android/Chrome وiPhone/Safari والكمبيوتر. متصفح مدمج داخل تطبيق آخر قد لا يسمح بالتثبيت؛ افتح الرابط في المتصفح الرئيسي. لا يمكن إجبار نظام التشغيل على عرض نافذة تثبيت.

التثبيت الفعلي ووضع الطيران يحتاجان اختبارًا على الأجهزة المستهدفة. أول زيارة تحتاج إنترنت.

## البنية
- `scripts/generate-content.mjs`: المصدر القابل للتدقيق لتوليد 1000 سؤال.
- `src/grammar-bank.json`: البنك الناتج، ويحمل كل سؤال المستوى والنموذج والتصنيف والتصحيح والشرح.
- `src/world.ts`: المدن والأماكن ومحتوى القرارات وبناء المسارات حسب المستوى.
- `src/learning.js`: الملف الشخصي واختيار التالي وتقدير الاختبار الداخلي.
- `src/engine.js`: التطبيع والنقاط وحفظ التقدم، مع توافق بيانات النسخة السابقة.
- `src/main.tsx`: الواجهة الثنائية والمكتبات والاختبارات والتثبيت.
- `tests/expanded.test.mjs`: أعداد البنك والتميّز والمسارات المستوية والاسم والتوجيه.

## البيانات والحدود
`parlequest-v1` للنتائج؛ `pq-profile-v3` للاسم والمستويات؛ `pq-run-v3` للمسار الحالي؛ `pq-language` للغة. مسح بيانات الموقع يمسحها. التصدير ينزل نسخة JSON؛ لا يوجد استيراد أو مزامنة بين الأجهزة في هذه النسخة. بيانات المحتوى المحلية القديمة لا تظهر بعد حذف المحرر. لا تُدخل معلومات طبية أو قانونية أو مالية حقيقية في الألعاب.

المستويات تصنيف تعليمي تقريبي. المحتوى يحتاج مراجعة مدرس FLE وتجربة طلاب قبل اعتباره بنكًا مقننًا. تتعلق المواقف الحساسة بمهارات اللغة والتواصل ولا تعطي إرشادًا طبيًا أو قانونيًا أو ماليًا.
